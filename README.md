# Bayan
Static site: `index.html` + `img/`. No build step.
Deploy: drag this folder to https://app.netlify.com/drop, or push to GitHub and enable Pages / Cloudflare Pages / Vercel (framework: Other, output dir: `.`).
Note: sign-in, profile, favourites and My Space are front-end demos stored in the browser (localStorage); there is no backend.
